# Future with Shivank AI Bootcamp

A standalone Python application scaffold for the Future with Shivank AI Bootcamp.

## Requirements

- Python 3.11 or newer
- [uv](https://docs.astral.sh/uv/)

## Run

```bash
uv sync
uv run future-with-shivank-ai-bootcamp
```

The starter entry point is in `src/future_with_shivank_ai_bootcamp/__init__.py`.
